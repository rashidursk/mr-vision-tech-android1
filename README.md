# MR Vision Tech — Flutter ERP foundation
Create a NEW private GitHub repository, upload all files including .github/workflows/build-flutter.yml, then run Actions > Build MR Vision Tech APK. Download the artifact and extract the APK. The workflow generates the Android scaffold. Local build: generate scaffold using the same workflow commands, then flutter pub get and flutter build apk --debug.
Implemented: local SQLite, dashboard, add/search stock and customers, POS with transactional stock deduction, invoice history and PDF sharing, light/dark theme. New independent database. No migration, login, backup/restore, barcode scanning, product editing, formal GST tax invoice compliance or custom logo yet. Do not use for production until these are implemented and tested. Flutter SDK is not available in the authoring environment; compilation and device tests remain pending.
